# Personal Portfolio

A modern, responsive full-stack portfolio website built to showcase my technical expertise, featured projects, and professional journey as a developer.

## 🚀 Features

* **Responsive UI**: A pixel-perfect, mobile-friendly design built with Tailwind CSS.
* **Interactive Animations**: Engaging user experience with smooth scroll reveals and element transitions powered by Framer Motion.
* **Dynamic Sections**:
    * **Hero**: High-impact introduction with custom CSS glowing effects.
    * **About**: Details my background as a dedicated Full Stack Developer focused on clean, scalable code.
    * **Projects**: Showcases key works with detailed descriptions, technology tags, and direct links to GitHub repositories.
    * **Skills**: A categorized breakdown of my technical stack across frontend, backend, database, and tools.
    * **Contact**: A dedicated functional area for professional inquiries.

## 🛠️ Tech Stack

### Frontend
* **React 19**: Modern UI library for building component-based interfaces.
* **Tailwind CSS 4**: For rapid, utility-first styling and responsive layouts.
* **Framer Motion**: For high-performance web animations.
* **Lucide React**: For a clean and consistent icon set.
* **Vite**: Next-generation frontend tooling for a fast development experience.

### Backend
* **Node.js & Express.js**: Powering the server-side logic and API endpoints.
* **Nodemailer**: Integrated for handling contact form submissions via email.
* **CORS & Dotenv**: For secure cross-origin resource sharing and environment variable management.
